## 🚀 Features / Practicals Covered

### 1️⃣ Tokenization

* Breaking text into words/sentences
* Basic preprocessing techniques

### 2️⃣ Bag of Words (BoW)

* Text vectorization using BoW
* Working with CSV dataset
* Frequency-based representation

### 3️⃣ Lemmatization

* Reducing words to base/root form
* Applied on a news dataset
* Uses NLP libraries for linguistic processing

### 4️⃣ Transformer Model

* Implementation of a **basic transformer model** using PyTorch
* Covers embeddings, attention mechanism basics
* Demonstrates modern NLP architecture
